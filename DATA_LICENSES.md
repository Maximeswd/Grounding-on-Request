# Data terms

| directory | content | origin | terms |
|---|---|---|---|
| `data/clevr3/` | Ground-CF in full | generated by this project | CC BY 4.0 (proposed; confirm before publishing) |
| `data/vcf/` | split manifests and item metadata; images rebuilt locally with `scripts/prepare_vcf.py` | `mgolov/Visual-Counterfact` | no licence tag on the Hub, so no images are redistributed |
| `data/color/` | split manifests; Arrow splits rebuilt locally with `scripts/prepare_task.py` | `stanfordnlp/colorswap` | MIT |
| `data/coco/` | split manifests and oracle-gate outputs; Arrow splits rebuilt locally with `scripts/prepare_coco_cf.py` | `Intel/COCO-Counterfactuals` | CC BY 4.0 |
| `data/mvg*/`, `data/multiventG/`, `data/multivent_raw_clean/` | derived text only: claims, descriptions, extracted-text strings, frame timestamps, evidence boxes; no frames, video or crops | MultiVENT-G and MultiVENT annotations, via `scripts/prepare_multiventg.py`, `scripts/multiventg_build_items.py`, `scripts/prepare_mvg_ctm.py` | MultiVENT-G terms (research use); the builders regenerate every file from the MultiVENT-G release |

The string `tyler day` in some MVG files is a name shown on screen in a news video (an extracted-text gold value), not a
person involved in the project.
